AUDIO RECORDER & STUDIO - ARCHITECTURE & SPECIFICATION BLUEPRINT
================================================================================

1. CORE TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
- Platform: Android Native (Kotlin)
- Orientation: Strict Portrait (Phones & Tablets)
- Target SDK: 36 (Android 16) | Min SDK: 24 (Android 7.0) | Compile SDK: 36
- Development Setup: Acode (Editor) + Git/GH CLI (Termux/Alpine)
- Cloud Build: GitHub Actions (Ubuntu runner, JDK 17, Gradle 8.7)
- Internal Processing: 32-bit IEEE Float PCM Scratchpad (Zero-clipping headroom)
- Background Execution: Android Foreground Service with PARTIAL_WAKE_LOCK


2. AUDIO ENGINE & SCRATCHPAD PIPELINE
--------------------------------------------------------------------------------
Capture Pipeline:
  [ Hardware Mic ] (Built-in / USB Audio / Bluetooth SCO)
         │
         ▼
  [ AudioRecord Native Thread ] (Captures 32-bit Float PCM)
         │
         ├───► [ Real-time Peak/RMS Math ] ───► [ Vertical dBFS Meter UI ]
         ├───► [ Voice Activity Detection ] ──► [ Prompter Auto-Pause ]
         │
         ▼
  [ Universal 32-bit Float Scratchpad ] (staging_session.raw)
         │
         │  • Direct random-access seek for live punch-in
         │  • Flushed to disk every 500ms
         │  • 5ms micro-crossfade applied at splice boundaries
         │
         ▼ (Upon Stop / Save)
  [ Export & Transcode Pipeline ]
     ├── WAV (16-bit, 24-bit, or raw 32-bit Float IEEE)
     ├── FLAC (Lossless compression via MediaCodec)
     ├── AAC / M4A & Opus (Compressed voice via MediaCodec)
     └── MP3 (Via LAME encoder integration)

Crash Recovery Sentinel:
  • Maintains sidecar JSON metadata (sample rate, channel layout, markers).
  • On app startup, checks for unfinalized sessions in cache.
  • Prompts one-tap session recovery or clean discard.

  • Filter Chips:

Recording Card UI:

      - Title, timestamp, duration, specs badge (e.g., 48kHz • 24b • Stereo).
      - File size, mini-waveform visual, and inline Play/Pause button.

      - Interactive scrubber timeline with draggable playhead.
      - Export: Save to SD card/device folder via SAF or share via App Intent.
      - Edit: Ingests take into Studio for punch-and-roll or append.
      - Rename & Delete: Inline rename dialog; soft delete to 30-day trash bin.

Batch Multi-Select Mode (Long-press any card):
  • Checkbox selection across all library cards.
  • Batch Export: Send multiple via system share sheet or zip to archive.
  • Batch Delete: Bulk trash bin relocation or permanent purge.

5. EDITING & PUNCH-AND-ROLL MECHANICS
--------------------------------------------------------------------------------
Universal Ingestion:
  • Existing recordings (WAV, FLAC, AAC, MP3) decode to 32-bit Float PCM
    scratchpad via MediaCodec before editing.

Punch-and-Roll Workflow:
  1. User scrubs visualizer to punch point (Time).
  2. Byte Offset = Time * SampleRate * Channels * 4 bytes.
  3. Pre-Roll: 3-second playback into headphones before recording starts.
  4. Replace Mode: Writes incoming float stream at byte offset.
  5. Anti-Click Micro-Crossfade: 5ms linear blend applied at splice point:
     Sample[n] = OldSample[n] * (1 - a) + NewSample[n] * a  (where 0 <= a <= 1)
  6. Safety Feedback Guard: Mutes monitor output if external speakers active.

Trimming:
  • Set Start and End marks; copies byte range to new scratchpad.
  • Applies 10ms micro-fade to boundaries to eliminate DC offset thumps.


6. REAL-TIME & EXPORT DSP EFFECTS PIPELINE
--------------------------------------------------------------------------------
1. High-Pass Filter (80 Hz):
   Attenuates low-end rumble and handling thumps.
   Formula: y[n] = alpha * (y[n-1] + x[n] - x[n-1])

2. Downward Noise Gate:
   Attenuates ambient room noise when audio falls below threshold (e.g., -45 dBFS).

3. De-Esser:
   Sidechain bandpass filter isolates 5kHz - 8kHz sibilance and dynamically
   compresses high-frequency peaks.

4. Peak Normalization:
   Scans peak float values and normalizes final mix to -1.0 dBFS ceiling
   prior to export.

================================================================================
MODIFICATION LOG: NON-DESTRUCTIVE RANGE REPLACEMENT & TAIL PRESERVATION
================================================================================
- Added Range-Splicing Workflow:
  Replaced destructive automatic truncation with a non-destructive dual-mode
  engine:
  1. Range Replacement (Punch-In to Punch-Out):
     - Downstream audio (Punch-Out to EOF) is sheltered to `tail_cache.raw`.
     - New audio is recorded from Punch-In onwards.
     - Upon stopping, `spliceTailBack()` appends the tail back onto the new take.
     - Dual-boundary 5ms micro-crossfades are applied at both splice points
       to eliminate boundary clicks.
  2. Overwrite to End (Classic Punch-and-Roll):
     - Explicit user action via `truncateAtSample()` when intentionally
       discarding downstream takes.
